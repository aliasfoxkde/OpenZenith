# OpenZenith
Elevation data that offers Efficiency, Simplicity, Coverage, Accuracy, and Size.

- Efficiency: This API has been optimized to use very few dependancies, including GIS Analysis tools that can be slow
  and it has an optimized search algorithm to use very low memory and CPU.
- Simplicity: Serverless solution with no setup (unlike setting up a traditional Elevation API that requires a lot of
  steps, getting data, conversion, chunking, and setup).
- Coverage: Provides elevation data for the entire world (the is possible by combining and compiling all publicly
  available DEM data into a single dataset with the highest resolutions).
- Accuracy: Highest elevation data pre-compiled from "best" available.
- Size: 99.88% reduction in size over traditional DEM's.

## What this tool is:
- A Light-Weight Serverless Elevation API that can be ran on mobile completely offline.
- This application is intended to return elevation data through an API endpoint (web, through JS), or included Python tools.

## What this tool is NOT!
- This tool is not intended for visualizing DEM data on a map, that is what LiDAR, Topopography, and Orthographic 
  Mosiacs are for. It is also not intended for traditional GIS Analysis. It serves a single purpose, so that it can
  be the best at just that! and offer Efficiency, Simplicity, Coverage, Accuracy, and Size.
